# Sistema de Login e Recuperação de Senha

Este projeto implementa um sistema básico de login com funcionalidade de recuperação de senha.

## Funcionalidades

- **Página de Login**: Interface para inserir email e senha
- **Recuperação de Senha**: Fluxo completo para solicitar recuperação de senha
- **Validação de Email**: Validação automática do formato do email
- **Navegação Intuitiva**: Navegação fluida entre as páginas
- **Design Responsivo**: Interface adaptada para diferentes tamanhos de tela

## Como Usar

1. Abra o arquivo `test.html` em um navegador web
2. Para testar o login: insira email e senha válidos e clique em "Entrar"
3. Para recuperar senha: clique em "Esqueci minha senha", insira seu email e clique em "Enviar Instruções"
4. O sistema simulará o envio de instruções de recuperação

## Estrutura do Projeto

- `test.html`: Página principal contendo todo o sistema de login e recuperação de senha
- `README.md`: Documentação do projeto

## Características Técnicas

- Interface responsiva com design dark
- Validação de email em tempo real
- Navegação SPA (Single Page Application)
- Feedback visual para o usuário
- Código JavaScript vanilla (sem dependências externas)
